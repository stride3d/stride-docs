# Upgrade to Stride 4.1

## Upgrade steps

The steps that upgrade a project from a version older than 4.1.

[!INCLUDE [upgrade-steps-intro](../includes/upgrade-steps-intro.md)]

### Stride-4.1.0-P1 Target .NET 6, and remove the Stride reference of Linux and macOS executables

Stride 4.1 runs on .NET 6. The step sets the `TargetFramework` of the project to `net6.0` (a library that targeted `netstandard2.0` or .NET Framework, an executable that targeted .NET Framework or .NET 5). It also removes the `Stride` package reference of Linux and macOS executables: they needed it only for `runtime.json`.

**By hand:** in the `.csproj`, set the target framework (`net6.0-windows` for a Windows executable):

```xml
<TargetFramework>net6.0</TargetFramework>
```

Remove this reference from the Linux and macOS executables:

```xml
<PackageReference Include="Stride" ... />
```

The later steps move .NET 6 on to the current .NET.
