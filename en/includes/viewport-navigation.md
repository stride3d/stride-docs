You can navigate the viewport by zooming and panning the camera. There is also a shortcut to quickly focus on an object, making the camera teleport itself to it.

| | Key | Description |
| :-: | :-: | :-- |
| | `Right mouse button` | Pan the camera |
| | `Scroll` | Zoom |
| | `F` | Focus on an object |

You can also move your camera around similarly to a video game by holding down the **Right mouse button** and pressing other keys.

| Key | Description |
| :-: | :-- |
| `W/A/S/D` or arrow keys | Move forwards/left/backwards/right |
| `Q/E` | Move down/up |
| `Shift` | Increase speed |

> [!TIP]
> All viewport keybinds can be changed in the settings.
