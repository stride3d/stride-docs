# AI usage (website)

Here are the guidelines for using AI on the [`stride-website`](https://github.com/stride3d/stride-website) repository:

* AI-generated text cannot be featured on any page
  * We allow using AI-powered autocorrect
  * We allow using AI for research purposes, summarizing parts of the engine or creating initial drafts, as long as its output isn't directly used in content
* AI cannot be used for creating any media content (e.g. images or videos)
* AI content cannot be featured in any media content (e.g. screenshot of an AI-generated model)
* We allow using AI for maintenance work (e.g. fixing formatting on pages)
* We allow using LLM models in accessibility features, such as providing localization support
  * Every place where users may face AI-generated content must be explicitly stated
