# AI usage (website)

AI usage is mostly forbidden on the [`stride-website`](https://github.com/stride3d/stride-website) repository:

* AI cannot be used for creating or editing content including html and css code, text or images
* AI cannot be used for other maintenance work (such as updating a link)

However, there are some exceptions to the above:

* We allow using AI-powered autocorrect
* We allow using LLM models in accessibility features, such as providing localization support
