# AI usage

These pages describe the guidelines for submitting contributions made with assistance of AI tools. The rules differ depending on the type of content and the repository where said content is submitted to.

## Quick summary

* We allow submitting code written with AI assistance, as long as it's not low-quality, the author understands it and can take full responsibility for it
  * An exception to this rule is code used in samples, in the documentation repository and in the website repository
* We forbid using generative AI to create assets such as images, audio or 3D models
* We forbid using AI for maintenance work on `stride-docs` and `stride-website` repositories
* We allow using LLMs for accessibility features, such as localization

We recommend you check out dedicated pages for each repository before submitting any PR:

* [Engine](engine.md)
* [Documentation](documentation.md)
* [Website](website.md)
