# AI contributions (engine)

This page describes the rules for using AI when contributing code to the [`stride`](https://github.com/stride3d/stride) repository.

## Respect the license

All tools that you use when contributing to the engine (including AI tools) need to be compatible with Stride's [MIT license](https://github.com/stride3d/stride/blob/master/LICENSE.md).

## AI-assisted code

We allow submitting code written with AI-assistance as long as:

* You **completely understand** how the generated code works and what it does
* You are able to **take full responsibility** for the code
* Your contribution reaches the **expected level of quality**
* Your contribution is submitted by you and **not a bot**

> [!NOTE]
> Samples and demos have different rules for AI-assisted code. See [Samples and demos](#samples-and-demos).

## AI documentation

While we forbid using AI on the documentation repository, the `docs/` folder in the main `stride` repository is an exception. You may use AI to create and edit pages for documenting the architecture.

## Generative AI usage

We forbid using any type of generative AI for creating 3D models, textures, sprites, sound effects, music, animations and other types of assets or art. If your contribution needs one of those, consider using free resources online that are compatible with Stride's [MIT license](https://github.com/stride3d/stride/blob/master/LICENSE.md).

## Samples and demos

We forbid using AI when contributing to samples or demos, including AI-assisted code, with the exception of autocorrect or other small tools that may utilize the technology.
