# AI usage (documentation)

Here are the guidelines for using AI on the [`stride-docs`](https://github.com/stride3d/stride-docs) repository:

* AI-generated text cannot be featured on any page
  * We allow using AI-powered autocorrect to write content
  * We allow using AI for research purposes, summarizing parts of the engine or creating initial drafts, as long as its output isn't directly used in content
  * Pages featured in the [engine architecture documentation](../../engine/architecture/index.md) are hosted on the [main engine repository](https://github.com/stride3d/stride) and follow its AI guidelines which allow AI-usage
* AI cannot be used for creating any media content (e.g. screenshots or visualizations)
* Screenshots taken for the documentation cannot feature AI-generated assets such as images or models
* We allow using AI for maintenance work (e.g. modifying the build script)
* We allow using LLM models in accessibility features, such as translating pages to unsupported languages
  * Every place where users may face AI-generated content must be explicitly stated
