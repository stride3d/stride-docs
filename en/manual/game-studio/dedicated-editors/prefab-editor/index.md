# Prefab editor

The **Prefab editor** allows you to edit [prefabs](../../../scenes/prefabs/index.md) similarly to how you would edit entities in a scene.

![](media/prefab-editor.webp)

It is almost identical to the **Scene editor**, with the exception of not being able to utilize scene-specific features (such as [sub-scenes](../../../scenes/sub-scenes.md)).

## Further reading

For information about how the editor works and how to use it, refer to the [Scene editor](../scene-editor/index.md) page.
