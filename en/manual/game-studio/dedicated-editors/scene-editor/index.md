# Scene editor

The **Scene editor** is one of the most important dedicated editors in Game Studio — it's where you will spent most of your time visually working on a game.

![](media/scene-editor.webp)

It consists of two parts:

* [Viewport](viewport.md) - a 3D/2D preview of the world, that can be used to explore and manipulate entities in a visual way.
* [Entity tree](entity-tree.md) - a tree showing every element that belongs to a scene.

![](media/scene-editor-layout.webp)
