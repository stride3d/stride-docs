# Script editor

Stride allows you to edit code directly through **Game Studio** using the built-in **Script editor**.

![](media/script-editor.webp)

Generally, it's recommended to use an IDE such as **Visual Studio** for programming, but if you like developing in a single application or do not have a need for a dedicated IDE, the **Script editor** can mostly suffice.
