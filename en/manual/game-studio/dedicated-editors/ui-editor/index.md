# UI editor

<span class="badge text-bg-primary">Beginner</span>
<span class="badge text-bg-success">Designer</span>

The **UI editor** is used for editing UI pages and libraries.

![](media/ui-editor.webp)

## Preview

The majority of the UI editor is taken up by the **Preview**. You can use it to view your UI, select individual elements and move them around.

![](media/preview.webp)

### Snap to grid

When moving elements around, they are snapped to a grid (1 unit by default). You can change the amount by which elements are snapped in the toolbar.

![](media/snapping.webp)

### Change tool colors

You can change colors of gizmos by pressing the **👁️ eye** icon in the toolbar.

![](media/colors.webp)

## UI library

This list shows all available ui element templates. You can drag them into the **Preview** or **Visual tree** in order to add them to your UI page or library.

![](media/ui-library.webp)

## Visual tree

The **Visual tree** shows the structure of the UI page or library in a tree-like structure. Elements can be rearranged, expanded and collapsed.

![](media/visual-tree.webp)

## UI Properties

In the top left corner of the editor there is a **UI Properties** button. Clicking it will display the general properties of the asset in the **Property grid**.

![](media/ui-properties.webp)
