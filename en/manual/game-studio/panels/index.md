# Panels

<span class="badge text-bg-primary">Beginner</span>

Game Studio's UI is comprised of multiple **panels** serving many purposes. **A lot of them influence each other**. For example: if you select an asset in the [Asset view](asset-view.md), it will cause the [Property grid](property-grid.md) to display its values.

You can change panel visibility by going to **View** and selecting the panel you want to show/hide.
